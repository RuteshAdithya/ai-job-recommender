# Deployment Guide

## Overview
This document provides instructions for deploying the AI Job Recommender app with ChatGPT integration to various cloud platforms.

## Prerequisites
- GitHub repository with all code committed
- OpenAI API key
- Apify API token

## Option 1: Streamlit Cloud (Recommended - Free & Easiest)

### Steps:
1. Go to [streamlit.io/cloud](https://streamlit.io/cloud)
2. Sign in with GitHub
3. Click "New app"
4. Select repository: `RuteshAdithya/ai-job-recommender`
5. Select branch: `main`
6. Set main file path: `app.py`
7. Click "Deploy"

### Add Secrets:
After deployment, go to app settings → Secrets and add:
```
OPENAI_API_KEY = "your_openai_api_key"
APIFY_API_TOKEN = "your_apify_api_token"
```

**URL:** `https://your-app-name.streamlit.app`

## Option 2: Heroku Deployment

### Prerequisites:
- Heroku account
- Heroku CLI installed

### Steps:
```bash
# Login to Heroku
heroku login

# Create app
heroku create your-app-name

# Set environment variables
heroku config:set OPENAI_API_KEY="your_openai_api_key"
heroku config:set APIFY_API_TOKEN="your_apify_api_token"

# Deploy
git push heroku main

# View logs
heroku logs --tail
```

**URL:** `https://your-app-name.herokuapp.com`

---

## Option 3: Google Cloud Run (Docker)

### Prerequisites:
- Google Cloud account
- Docker installed
- Google Cloud CLI

### Steps:
```bash
# Authenticate
gcloud auth login

# Create GCP project
gcloud projects create ai-job-recommender

# Configure Docker
gcloud auth configure-docker

# Build Docker image
docker build -t gcr.io/PROJECT_ID/ai-job-recommender:latest .

# Push to Google Container Registry
docker push gcr.io/PROJECT_ID/ai-job-recommender:latest

# Deploy to Cloud Run
gcloud run deploy ai-job-recommender \
  --image gcr.io/PROJECT_ID/ai-job-recommender:latest \
  --platform managed \
  --region us-central1 \
  --port 8501 \
  --set-env-vars OPENAI_API_KEY="your_key",APIFY_API_TOKEN="your_token"
```

**URL:** Generated by Google Cloud Run

---

## Option 4: AWS EC2 + Docker

### Prerequisites:
- AWS account
- EC2 instance with Docker installed

### Steps:
```bash
# SSH into your EC2 instance
ssh -i your-key.pem ec2-user@your-instance-ip

# Pull Docker image
docker pull your-image-name

# Run container
docker run -d \
  -p 8501:8501 \
  -e OPENAI_API_KEY="your_key" \
  -e APIFY_API_TOKEN="your_token" \
  your-image-name
```

## Troubleshooting

### Issue: "OPENAI_API_KEY is missing"
- Ensure environment variable is set in your deployment platform
- For Streamlit Cloud, add it in Secrets
- For Heroku, use `heroku config:set`

### Issue: "No module named 'openai'"
- Ensure `requirements.txt` includes `openai`
- Reinstall: `pip install -r requirements.txt`

### Issue: Slow API responses
- OpenAI API calls may take 5-10 seconds
- Consider using `gpt-3.5-turbo` instead of `gpt-4` for faster responses
- Set higher `max_tokens` for detailed responses

### Issue: Resume upload fails
- Check file size (max 5 MB)
- Ensure PDF is text-based (not scanned image)
- Try a different PDF reader tool first
